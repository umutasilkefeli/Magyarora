# Magyar Füzet

Macarca A1 çalışma uygulaması: kartlar, testler, çekim alıştırması, okuma metinleri ve konu tabloları (Türkçe ipuçlarıyla).

Telefonda açıp **Ana ekrana ekle** dersen uygulama gibi çalışır, internetsiz de açılır.

## Ders arşivi (ders.html)

Livia Akcal Nyáry ile yapılan Teams derslerinden derlenen sayfa: 20 ünitelik konu akışı, okumalar, kelime kartları, testler ve 54 dersin tam arşivi. Ana uygulamadaki **Ders arşivi** sekmesinden açılır; doğrudan `ders.html#arsiv` ile arşive gidilebilir.
